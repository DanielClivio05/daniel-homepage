Projects

StackedRoster

stackedroster.net

An independent ranking system for NCAA Division I college tennis, men's and women's. It pulls match results from the ITA's API, computes its own ranking from them, and publishes the list next to a live comparison against the official one — so anyone can see exactly where the two disagree, including when mine is wrong.

Next.js · TypeScript · Supabase / Postgres · Vercel · scheduled GitHub Actions — around 16,000 lines, sole developer

booknooklane.com

The system an independent bookstore runs on: inventory, sales, events, customer bookings, and a bilingual public site the owner edits herself without needing a developer.
